# CCCD Crop & Print (WinForms)

Ứng dụng WinForms demo để:

1. Nạp ảnh CCCD mặt trước/mặt sau.
2. Tự cắt viền theo thẻ (Auto Crop).
3. Ghép 2 mặt theo hàng ngang.
4. Chọn số lượng và in.

## Yêu cầu

- .NET 6 SDK
- Windows (WinForms)

## Chạy

```bash
cd src/CCCD.WinForms
dotnet run
```

## Gợi ý sử dụng

- Chụp ảnh thẻ phẳng, đủ ánh sáng.
- Bấm **Auto Crop** để lấy vùng thẻ.
- Bấm **Combine** để tạo ảnh ghép.
- Chọn số lượng và **Print**.
